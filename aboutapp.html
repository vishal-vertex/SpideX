About Spidex App

Spidex App is a lightweight educational file-sharing platform designed and developed specifically for students. The app allows the admin to upload important academic materials, which students can access and download at their convenience.

Developer

This app was proudly built by Vishal, a 2nd-year Artificial Intelligence student with a passion for building practical solutions using modern web technologies like HTML, JavaScript, Node.js, and Supabase.

Purpose

The primary goal of Spidex App is to simplify how students access study materials. Admins can easily upload files to Supabase Storage, and students can quickly browse and download them through an elegant interface.

Key Features

  • Simple dashboard UI
  • 3D solid glassmorphism menu design
  • Cloud storage powered by Supabase
  • Responsive design for both PC and Android
  • Mini games like 2048 included for brain breaks
